{% comment %} Dark mode for the HTML mails. Email has no stylesheet cascade to lean on: every rule in these templates is an inline style attribute, and an inline style beats a class selector. So the dark rules below carry `!important`, which is the only thing that outranks an inline declaration, and the templates tag their elements with the em-* classes this block names. Two delivery paths, because mail clients disagree about dark mode: - `prefers-color-scheme` (Apple Mail, iOS, Outlook for Mac, Thunderbird, Gmail on mobile) honours the media query below. - Outlook.com and Outlook on Windows do not report the media query; they set `data-ogsc` on and expect explicit overrides. Those rules therefore sit outside the media query. The `color-scheme` meta and :root declaration are what stop Apple Mail from inverting the whole message itself, which would double-apply our colours. Not covered, deliberately: Allauth's mail templates. The only ones this repo overrides are plain text (`templates/account/email/*.txt`), and text mail has no colours to theme. {% endcomment %}
